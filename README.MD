# Machine Pets

**Game Jam:** Gamedev.js Jam 2026  
**Theme:** MACHINES  

## Description
You are a house cat who once lived freely—making messes, claiming territory, and ruling the home. One day, your owners replace you with a robotic pet: cleaner, smarter, and more obedient.  
Now abandoned, you are determined to destroy the machine and reclaim your place.

## Controls
Waiting

## Mechanics
- Select plans from the cat’s thoughts  
- Each level represents a unique attempt to destroy the robot  
- Failed attempts are permanently locked (no retries)  
- Progress by finding the successful plan  

## Objective
Eliminate the robotic pet and return home
